# twitchwii-project
Unofficial Twitch client for the Nintendo Wii (homebrew). Browse live streams, categories and channels, watch live streams and VODs, and read live chat directly from the Wii with a Twitch-style interface. Installs as a Wii Menu channel (WAD) or a Homebrew Channel app.

## Companion server (optional)

The app works without a PC server (it can talk to Twitch over HTTPS). To use HTTP proxy or transcoded playback, run `server/twitchwii_server.py` on a computer on the same network and enter that PC's IP address in Settings. See `server/README.md` for options. Tokens and Helix client secrets are optional and are read from command-line flags or environment variables; they are not stored in the repository.

## Languages

The interface is available in 11 languages: English, Spanish (Español), French (Français), German (Deutsch), Italian (Italiano), Dutch (Nederlands), Portuguese – Brazil (Português), Japanese (日本語), Simplified Chinese (简体中文), Traditional Chinese (繁體中文) and Korean (한국어).

- The language is picked automatically from the Wii system language (Spanish, French, German, Italian, Dutch, Japanese, Simplified Chinese, Traditional Chinese and Korean map directly; any other console language falls back to English). Portuguese can be chosen manually.
- It can be changed at any time in **Settings → Interface language** (also reachable with the Classic and GameCube controllers); each language is listed under its own name.
- The choice is saved on the SD card (or USB) next to the account configuration, in `idioma-interfaz.txt`. The stream language filter (`idioma.txt`) is separate.
- All strings live in one table (`wii-client/source/i18n_table.c`, generated by `wii-client/tools/i18n/gen.py`); translations were written without native review, so corrections are welcome.

### CJK font

The built-in UI font only covers Latin characters, so Japanese, Chinese and Korean use a tiny bitmap subset of **Noto Sans CJK** (Regular and Bold; Copyright Google / Adobe, licensed under the [SIL Open Font License 1.1](wii-client/licenses/NotoSansCJK-OFL-1.1.txt)). Only the glyphs actually used by the JA/ZH/KO string tables and the language names are rasterised (4-bit alpha, at the UI font sizes, `wii-client/tools/i18n/gen_cjk.py`) and stored zlib-compressed; the set for a language is inflated into memory only while that language is active, and freed when you switch to a Latin one.

Limitation: only UI text is covered. Twitch stream titles, chat messages and channel names written in Japanese, Chinese or Korean can still show missing glyphs.
