# twichwii-project
Unofficial Twitch client for the Nintendo Wii (homebrew). Browse live streams, categories and channels, watch live streams and VODs, and read live chat directly from the Wii with a Twitch-style interface. Installs as a Wii Menu channel (WAD) or a Homebrew Channel app.
